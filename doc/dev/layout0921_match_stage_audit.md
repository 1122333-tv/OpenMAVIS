# Layout0921 前双目匹配分阶段审计

## 方法与结论

2026-09-24，分支 codex/openmavis-layout0921-prepared。对全部1195组分别构造关闭/开启有效射线过滤的真实Frame，逐候选调用原TriangulateMatches。每帧ratio=0.8接收数与Frame内部匹配数量逐一断言一致，完整运行通过。没有改变生产阈值，本次也不是VIO回放。

主要瓶颈是候选不足及几何一致性不足，启动阶段尤其严重。视差门限不是主要瓶颈，不建议放宽正深度或重投影检查。

## 全量阶段统计

开启有效射线过滤、ratio=0.8。共1,125,035个左查询；1,079,841个被比值测试拒绝，45,194个进入三角化（约4.02%）。以下分类是顺序短路的首次失败原因，不能因为右图重投影淘汰少就推断右图模型更准确。

| 右负/零深度 -3 | 1,649 | 3.65% |

| 右重投影超限 -5 | 210 | 0.46% |

| 深度不超过0.0001 | 0 | 0.00% |
| 最终通过 | 18,714 | 41.41% |

全量每帧通过数中位数15，右索引去重后中位数13；595/1195帧少于15个通过点。18,714条通过关联覆盖累计16,136个不同右特征，即2,578条关联重复占用右特征，不能把原通过计数等价为独立三维点。右索引去重也只是必要条件，并非完整地图点去重。

关闭有效射线过滤时总通过18,490，中位数14；过滤后总通过18,714，中位数15。过滤改善有效域，但没有使前双目深度支持充分。

## 建议下一步

1. 初始化应检查去重后的有效三角化点数量、图像覆盖及跨帧持续性，不能仅凭四路总特征数大于500就建图。可将30/50个独立点作为待验证的对照门限；不足则等待，避免创建1–4个点的地图。这只阻止无效初始化，不保证能跟踪。
2. 优先优化候选产生：先用标定射线的极线/深度可行性约束缩小候选，再做描述子排名与比值测试，并加入双向一致性或一对一分配。先输出候选叠图检查匹配歧义、重叠区和图像/标定几何一致性；负深度不能单独证明一定是描述子错配。
3. 评估跨相机深度初始化，优先cam1–cam3，其次cam0–cam2。需把点变换到统一cam0/IMU参考系，合并跨对重复观测并扩展Frame/KeyFrame/MapPoint索引；不能只加计数或随意交换相机槽位。
4. 各项独立实验，先核对独立点数、初始化时间和重置次数，再完整回放1195组验证初始化后OK≥95%、末帧OK且无初始化后重置。本次保留ratio=0.8及全部几何门限，不以静态匹配计数代替轨迹验收。

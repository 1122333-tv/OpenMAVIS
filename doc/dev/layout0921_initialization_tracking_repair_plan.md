## 2. 已有证据与诊断重点

历史有效射线过滤回放处理 1195 帧，首次 IMU 初始化在第 201 帧，初始化后 OK 为 58.15%，末帧 RECENTLY_LOST；这些历史指标不能替代本轮复跑。

前 128 帧前双目三角化通过中位数为 4，右索引去重后为 3；比值测试后的候选中 67.33% 被非正深度拒绝。当前初始化只检查四路总特征数超过 500。分阶段统计详见 `layout0921_match_stage_audit.md`。

优先验证源码问题：侧相机计算 uvsl/uvsr 但窗口使用前相机 uv；右相机调用左相机模型；前相机不可见或无候选会跳过其他相机；重复观测、侧相机索引、参考相机距离及最后观测删除边界需要最小测试。

同时诊断候选不足、脆弱建图、惯性初始化和优化后内点损失，不提前认定唯一根因。

## 3. 实验与修改顺序

一次改变一个因素，保存失败结果；前一阶段未验收通过再推进扩展。

| 阶段 | 工作 | 判断依据 |
| --- | --- | --- |
| E0 | 原配置完整回放一次，有效射线配置三次 | 初始化、重置、失败区间、重复波动 |
| E1 | 分开修复相机模型、侧相机窗口、前相机提前退出 | 正确对应进入候选，四路匹配和优化内点 |
| E2 | 测试复现后逐项修复索引、计数、最后观测、参考距离 | 观测一致性、内存检查、回放 |
| E3 | 标定几何候选、双向一致性、一对一匹配 | 独立点、重投影、跨帧存活 |
| E4 | 原门槛与 30/50 个独立点及空间覆盖对照 | 脆弱建图和初始化延迟 |
| E5 | 必要时依次加入 cam1–cam3、cam0–cam2 | 去重支持和连续跟踪 |
| E6 | 视觉可靠但惯性优化后失败时查预积分、重力、偏置 | 解析测试和优化前后残差 |
| E7 | 冻结配置，两段数据各完整回放三次 | 每次均达验收 |

诊断运动模型、参考关键帧和局部地图阶段；各路记录可见点、候选、匹配、内点，另记独立地图点。视觉建图和 IMU 初始化分别记录点数、关键帧数、预积分时长、重力、偏置、速度、优化前后残差和重置原因。线程独立记录再关联，避免新增同步影响行为。叠图覆盖前 128 帧、初始化附近和失败前后，保留全部淘汰阶段。

匹配候选：射线极线残差用反投影雅可比和金字塔方差归一化，初始卡方门槛 3.841；ratio 0.8，绝对 Hamming TH_LOW=50。单一候选必须通过绝对距离、双向检查和完整三角化并单独统计。保持原视差、正深度和重投影门槛。

初始化覆盖用每路 4×3 网格，至少两路各覆盖不少于 4 格；点数不足等待。跨相机种子存 cam0 坐标和四路全局索引，只检查观察相机的正深度。共享特征且所有重投影一致才合并，冲突保留归一化误差更小者。初始化和后续关键帧共用种子消费，复用四相机观测结构。

方向直方图先不改变；如果剔除已验证正确的跨相机对应另设对照。保留 CLI 与原入口，增加可选详细诊断；实验 YAML 显式选匹配模式、相机对和质量门槛，缺省保持原行为。仅解析测试证明反投影/积分错误时改实现，不用噪声、偏移或优化阈值调参替代定位。

## 4. 测试与验收

测试覆盖四路不同内外参、局部/全局索引、仅侧相机可见、前相机无候选、非正深度、边界；合成投影/反投影/三角化/优化残差；一对多、种子冲突、重复和最后观测、参考距离；IMU 零/单/边界样本、恒角速/恒加速度及区间时长。复跑入口/汇总测试，构建新旧入口，git diff --check；索引/生命周期测试使用 ASan/UBSan。

各修改先针对性测试和前 300 帧短回放，再完整回放；未初始化不能宣称成功。

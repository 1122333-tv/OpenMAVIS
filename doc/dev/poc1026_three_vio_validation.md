# 1026 POC：OpenMAVIS、OKVIS2、Basalt 在线 VIO 对比

日期：2026-10-28。OpenMAVIS 从既有 OKVIS2 v2 run 导入相同的四目配组数据、calibration_1023_B、冻结的 Basalt/OKVIS2 在线轨迹和 IMU/body GT。先完整验证 small_move，再依次运行其余五包；六包每包只运行一次 OpenMAVIS。参考算法没有重新执行。

## 实现与口径

新增显式 `--imu-bias-policy estimate-from-zero`，允许非零固定 bias 元数据，保留原始 IMU、零初始 bias、在线估计；拒绝非有限或非零尺度/非正交校正。默认 `require-zero` 及 legacy 评测保留。C++ 算法没有修改，复用与源码快照一致的 build-vio 二进制。

新增 `--evaluation-profile static|motion`。静止按各评测窗口起始有效 1 s 平均位姿对齐，运动按整段匹配位置 SE(3) 对齐，均不拟合尺度。报告 APE/ARE 与 0.1/1 s RPE/RRE，运动另加 0.1/0.5/1 m。Common 使用精确整数纳秒共同时间戳和完全相同帧对，并合并所有算法的 GT 空洞、输出间断和已知重置边界。Native 单列，不用于相同样本排名。

OpenMAVIS 在线轨迹只保留 OK、已 IMU 初始化且有限的样本；不使用最终地图回溯轨迹，不拼接多个已初始化坐标段。GT 冻结，不重新对时或再次应用 marker 外参。相机时间偏移 +5,449,054 ns 只应用一次。
